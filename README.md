# Boost Feed

Jason's self-hosted Boost Feed. Free hosting on GitHub Pages.

- index.html: the page
- channels.json: YouTube channels whose newest videos play in each set
- picks.txt: Instagram and TikTok posts to show inside the feed
- feed.json: filled in automatically every 3 hours (don't edit)
- scripts/update_feed.py + .github/workflows/update.yml: the automatic update job
